## 최신 버전

### v0.0.3 (Windows x64)

링크 오른쪽 위의 복사 버튼을 눌러 주소를 복사해서 브라우저 주소창에 붙여 넣으면 바로 다운로드됩니다.

**바로 다운로드 링크 (zip, 약 330MB)**

```
https://github.com/Zohs108/JhsBrief-releases/releases/download/v0.0.3/JhsBrief-0.0.3-win-x64.zip
```

**릴리스 페이지 링크**

```
https://github.com/Zohs108/JhsBrief-releases/releases/tag/v0.0.3
```

설치와 실행 방법은 zip을 푼 폴더의 `사용안내.txt`를 보세요. 짧은 경로(예: `C:\JhsBrief`)에 풀고, OneDrive 폴더는 피하세요.

업데이트할 때는 프로그램을 끈 뒤 `app` 폴더, `JhsBrief.exe`, `사용안내.txt`를 교체하세요. `data`와 `workspace`는 그대로 둡니다.
